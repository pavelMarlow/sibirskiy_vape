# Сибирский — Telegram WebApp

Статическая версия для GitHub Pages.

## Публикация

1. Загрузите все файлы из этой папки в корень репозитория.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, Folder: / (root).
5. Сохраните и дождитесь публикации.

WebApp использует `catalog-preview.json` и localStorage, поэтому сервер API для каталога не требуется. Админка и серверные операции из исходной Cloudflare-версии в GitHub Pages не работают.
